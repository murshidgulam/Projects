# 📝 Todo App

A simple and interactive Todo List application built using **HTML, CSS, and Vanilla JavaScript**. It helps users manage their daily tasks with an easy-to-use interface.

🔗 **Live Demo:** https://murshidgulam.github.io/Projects/todo-app/

## ✨ Features

* **Add Tasks:** Create new tasks easily.
* **Delete Tasks:** Remove tasks you no longer need.
* **Mark as Completed:** Track completed tasks using checkboxes.
* **Filter Tasks:** View All, Active, or Completed tasks.
* **Clear Completed:** Remove all completed tasks with one click.
* **Remaining Tasks Counter:** Keep track of pending tasks.
* **Local Storage:** Automatically save tasks in the browser so they remain available after refreshing the page.

## 🛠️ Technologies Used

* HTML5 – Application structure.
* CSS3 – Styling and layout.
* JavaScript (ES6+) – Application logic and DOM manipulation.
* LocalStorage – Client-side data persistence.


2. Navigate to the project folder:

   ```bash
   cd Projects/todo-app
   ```

3. Open `index.html` in your browser.
